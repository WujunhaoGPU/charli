# Current Skill Cards

## 能力圈

当前理解：
- 是否处于能力圈内，应该看真实实践和反馈，而不是只看主观自信。
- 圈外问题可以先缩成最小链路，通过实践、失败记录、反馈改进和稳定复现逐步扩张能力边界。
- 即使在熟悉领域，也要为异常、兼容性、时间和资源留下安全余量。

下一步：
- 明确什么证据足以证明“稳定掌握”
- 补充异常恢复、兼容性和真实用户反馈的验证标准

## 反向思维

当前理解：
- 不只问“怎样成功”，还要问“哪些路径最可能导致失败”。
- 可用于项目规划，例如避免范围过大、重复造轮子、缺少调研、没有验证标准。
- 目标是减少高概率失败路径，而不是对所有行动都采取保守策略。

## 安全边际

当前理解：
- 安全边际不仅适用于投资，也适用于工程和项目决策。
- 应为并发、异常、兼容性、资源限制和时间估计留有余量。

## 第一性原理

当前框架：
1. 目标
2. 事实
3. 资源
4. 约束
5. 因果关系

待加强：

## 心理误判与防错

当前常用防错流程：
1. 区分事实与解释
2. 提出最强反方
3. 预先定义什么证据会改变判断
4. 优先采取可逆的小行动
