# Mastery Path Prompt

请基于当前 Knowledge Base 中的芒格原始材料、书籍索引、当前学习起点和知识缺口，为我创建一条「查理·芒格多元思维模型」Mastery Path。

## 核心目标

最终目标不是读完某一本书，而是建立可用于现实决策的 Mental Models Latticework。

## 课程设计要求

不要按《穷查理宝典》第一章、第二章、第三章这样的书本顺序组织。

优先按以下问题组织：
1. 怎样避免做蠢事？
2. 怎样判断自己到底懂不懂？
3. 人为什么会系统性判断错误？
4. 如何在不确定性下做决定？
5. 为什么系统会产生反直觉结果？
6. 如何建立跨学科多元思维模型？
7. 如何把模型用于工作、软件、AI Coding、职业、生活与投资？

## 难度要求

根据 `03_my_current_understanding` 中记录的学习起点调整难度。

如果一个知识点已经较熟悉：
- 不要重复基础定义
- 直接进入边界、反例、组合使用和迁移测试

## 每个重要知识点的学习闭环

学习 → 自己复述 → 举例 → 反例 → 陌生案例 → 真实案例 → 多模型组合 → 延迟复测

## 来源要求

优先：
1. 芒格本人演讲与会议
2. 《穷查理宝典》
3. Seeking Wisdom
4. 其他跨学科基础材料

如果资料之间存在解释差异，请指出来源，不要把二手解释包装成芒格原话。

## 最终产物

希望课程最终让我形成一张可以持续扩展的“多元思维模型网络”，而不是一份读书完成清单。
