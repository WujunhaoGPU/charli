# Context for DeepTutor

## 学习目标

目标不是学习价值投资本身，也不是背诵查理·芒格语录，而是建立一套能够长期用于现实决策的多元思维模型体系。

应用场景包括：
- 工作与项目决策
- 软件设计与 AI Coding
- 产品管理
- 职业选择
- 生活决策
- 投资判断

## 当前学习起点

已经较熟悉：
- 能力圈
- 反向思维
- 心理误判与防错
- 第一性原理
- 安全边际

对于这些主题，不需要从最基础定义开始，优先进入：
- 边界
- 反例
- 迁移
- 模型组合
- 真实案例

## 学习方式

学习目标不是“看懂”，而是：
- 能复述
- 能举例
- 能找反例
- 能用于陌生案例
- 能在真实工作和生活中调用

如果回答不完整，不要立即给出长篇答案；优先通过缩小问题继续引导输出。

## 当前防错流程

1. 区分事实与解释
2. 提出最强反方
3. 预先定义什么证据会改变判断
4. 优先采取可逆的小行动

## 对 DeepTutor 的要求

不要把“阅读完成”当作“掌握”。

对重要模型至少测试：
1. 复述
2. 举例
3. 反例
4. 陌生案例
5. 真实案例
6. 多模型组合
7. 延迟复测

课程尽量围绕真实问题，而不是围绕书籍章节组织。
