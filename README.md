# Charlie Munger Learning Pack

这是一个为 DeepTutor「精通之路 / Mastery Path」准备的学习资料仓库。

目标不是“读完几本芒格相关书”，而是建立一套可以真正用于现实决策的多元思维模型体系，并让 DeepTutor 在生成学习路线时同时知道：

1. 芒格本人讲过什么；
2. 哪些材料可信、应该优先；
3. 学习者当前已经掌握到什么程度；
4. 还有哪些知识缺口；
5. 什么才算“真正掌握”。

## 仓库结构

- `01_sources/`：书籍、演讲、会议与资料优先级
- `02_munger_core/`：芒格核心思想地图
- `03_my_current_understanding/`：当前已有理解，供 DeepTutor 同步学习起点
- `04_learning_gaps/`：当前待补知识与需要验证的误区
- `05_mastery_path/`：学习目标、路线草案、掌握等级与测试规则
- `06_deeptutor/`：直接提供给 DeepTutor 的上下文与建路提示

## 使用方式

建议先把本仓库中的 Markdown 资料导入 DeepTutor Knowledge Base，再单独导入你合法拥有的《穷查理宝典》等书籍 PDF/EPUB。最后使用 `06_deeptutor/context-for-deeptutor.md` 和 `06_deeptutor/mastery-path-prompt.md` 创建 Mastery Path。

## 原则

- 原典优先于二手解读
- 不把“看懂”当作“掌握”
- 已经达到 L3/L4 的知识点不重复从定义开始
- 重要模型必须经过复述、反例、陌生案例、跨模型组合和延迟复测
- GitHub 只保存自建笔记、公开来源索引与课程上下文；不上传未经授权的受版权保护整本书
