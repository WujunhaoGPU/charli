# Mastery Framework

## 总目标

建立一套能够真正用于现实决策的芒格式多元思维模型体系。

学习结束时，不要求记住所有芒格语录，而要求能够：
- 准确解释重要模型
- 判断模型的适用边界
- 识别反例
- 在陌生问题中选择模型
- 组合多个模型
- 根据新证据修正判断
- 把模型用于真实项目和生活决策

## 掌握等级

### L1 — 识别
听到概念知道大致是什么意思。

### L2 — 解释
能不用原文，用自己的话说清楚。

### L3 — 使用
能在给定案例中正确调用。

### L4 — 迁移
能在陌生真实问题中主动调用，并识别边界、反例和失败条件。

### L5 — 组合
能同时使用多个模型，对不同模型给出的结论进行交叉校验，并形成自己的决策流程。

## 一个知识点的最低测试

重要模型至少经过：
1. 30 秒复述
2. 自己举例
3. 识别反例或边界
4. 陌生案例
5. 真实问题应用
6. 与其他模型组合
7. 延迟复测

## 学习路线设计原则

课程应按“决策问题”组织，而不是按书籍章节机械组织。

建议模块：
1. 怎样避免做蠢事
2. 怎样知道自己到底懂不懂
3. 人为什么会系统性判断错误
4. 如何在不确定性下决策
5. 系统为什么产生反直觉结果
6. 如何建立多元思维模型
7. 如何把模型用于真实生活与项目
